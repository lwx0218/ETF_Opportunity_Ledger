
```bash

cd auto_filter_stock
```

## 🔧 常见问题快速解决

### 问题1：找不到数据文件
**错误信息**：`FileNotFoundError: [Errno 2] No such file or directory: 'data/daily_screening_results.csv'`

**解决方案**：
1. 确保 `data/` 文件夹存在
2. 确保三个数据文件都在 `data/` 文件夹中
3. 检查文件名是否正确

### 问题2：依赖包安装失败
**错误信息**：`ERROR: Could not find a version that satisfies the requirement`

**解决方案**：
```bash
# 升级pip
pip install --upgrade pip

# 使用国内镜像安装
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple/
```

### 问题3：程序运行缓慢
**现象**：程序运行时间很长

**解决方案**：
1. 检查数据文件大小，如果太大可以截取部分数据测试
2. 确保有足够的内存（建议4GB+）
3. 关闭其他占用内存的程序
