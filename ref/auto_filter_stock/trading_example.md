# 买入卖出计算示例

## 📈 正常股票交易示例

### 买入计算
```
股票: 000001.SZ 平安银行
开盘价: 10.00元
滑点率: 0.1%
实际买入价: 10.00 × (1 + 0.001) = 10.01元

分配资金: 100,000元
可买股数: 100,000 ÷ 10.01 ÷ 100 × 100 = 9,900股
买入金额: 9,900 × 10.01 = 99,099元
手续费: max(99,099 × 0.000086, 5) = 8.52元
总成本: 99,099 + 8.52 = 99,107.52元
```

### 卖出计算
```
持有1天后卖出
最高价: 10.50元
最低价: 10.20元
平均价: (10.50 + 10.20) ÷ 2 = 10.35元
滑点率: 0.1%
实际卖出价: 10.35 × (1 - 0.001) = 10.33965元

卖出金额: 9,900 × 10.33965 = 102,362.54元
手续费: max(102,362.54 × 0.000086, 5) = 8.80元
净收入: 102,362.54 - 8.80 = 102,353.74元

单笔收益: 102,353.74 - 99,107.52 = 3,246.22元
收益率: 3,246.22 ÷ 99,107.52 = 3.28%
```

## 🚫 涨停股处理示例

### 买入涨停股
```
股票: 000002.SZ 万科A
开盘价: 0元 (涨停，无法获取开盘价)
前日收盘价: 15.00元
系统处理: 使用前日收盘价 15.00元
实际买入价: 15.00 × (1 + 0.001) = 15.015元

结果: 系统会尝试按15.015元买入，但实际可能无法成交
```

### 卖出涨停股
```
持有股票: 000002.SZ 万科A
买入价: 15.015元
当日最高价: 16.50元 (涨停价)
当日最低价: 16.50元 (涨停价)
平均价: (16.50 + 16.50) ÷ 2 = 16.50元
实际卖出价: 16.50 × (1 - 0.001) = 16.4835元

结果: 按涨停价卖出，获得最大收益
```

### 卖出跌停股
```
持有股票: 000003.SZ 国农科技
买入价: 20.00元
当日最高价: 18.00元 (跌停价)
当日最低价: 18.00元 (跌停价)
平均价: (18.00 + 18.00) ÷ 2 = 18.00元
实际卖出价: 18.00 × (1 - 0.001) = 17.982元

结果: 按跌停价卖出，承受最大损失
```

## 🔍 系统处理逻辑总结

### 买入逻辑
1. **优先使用开盘价**
2. **开盘价无效时使用前日收盘价**
3. **价格为0时跳过该股票**
4. **应用滑点增加买入成本**

### 卖出逻辑
1. **优先使用当日平均价**
2. **平均价无效时使用买入价**
3. **涨停股按涨停价卖出**
4. **跌停股按跌停价卖出**
5. **应用滑点减少卖出收入**

### 风险控制
1. **价格验证**: 确保价格数据有效
2. **异常处理**: 数据缺失时的备用方案
3. **成本计算**: 完整的手续费和滑点计算
4. **资金管理**: 确保有足够资金完成交易
