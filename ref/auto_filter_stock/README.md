# 强势股策略回测系统

## 📊 项目简介

这是一个基于强势股筛选的量化投资回测系统，通过分析股票的技术指标和动量特征，筛选出具有强势特征的股票组合，并进行不同持有期的策略回测分析。

## 🎯 核心功能

- **强势股筛选**: 基于技术指标和动量分析筛选优质股票
- **多策略回测**: 支持1天、2天、1周等不同持有期策略
- **详细交易记录**: 生成每笔交易的详细CSV记录
- **可视化分析**: 自动生成策略对比图表
- **基准对比**: 与沪深300指数进行收益对比

## 📊 数据准备

### 必需数据文件

确保 `data/` 目录下包含以下文件：

1. **daily_screening_results.csv** - 每日筛选结果
   - 包含字段：筛选日期、股票代码、股票名称等
   
2. **trading_data.dta** - 股票交易数据
   - 包含字段：Stkcd（股票代码）、Trddt（交易日期）、Opnprc（开盘价）、Hiprc（最高价）、Loprc（最低价）、Clsprc（收盘价）等
   
3. **CS300.dta** - 沪深300基准数据
   - 包含字段：Trddt（交易日期）、Clsprc（收盘价）等

### 数据格式要求

- 日期格式：YYYY-MM-DD
- 股票代码：标准格式（如：000001.SZ, 600000.SH）
- 价格数据：数值型，单位为元

## 📈 策略说明

### 回测策略

1. **持有1天策略**
   - 每日根据前一日筛选结果买入强势股
   - 次日卖出，重新调仓
   - 适合捕捉短期动量

2. **持有2天策略**
   - 买入后持有2个交易日
   - 到期后清仓重新买入
   - 平衡交易频率和收益

3. **持有1周策略**
   - 买入后持有5个交易日
   - 减少交易频率，降低交易成本
   - 适合中长期趋势

### 交易规则

- **买入价格**: 开盘价 + 滑点（0.1%）
- **卖出价格**: 当日平均价（最高价+最低价）/2
- **手续费**: 0.0086%
- **调仓逻辑**: 持有到期后清仓重新买入

3. **超额收益**: 策略相对基准的超额表现

## ⚠️ 注意事项

1. **数据质量**: 确保数据文件完整且格式正确
2. **交易成本**: 回测已考虑手续费和滑点，实际交易成本可能更高
3. **流动性假设**: 假设所有股票都能按设定价格成交
4. **市场冲击**: 未考虑大额交易对价格的影响
