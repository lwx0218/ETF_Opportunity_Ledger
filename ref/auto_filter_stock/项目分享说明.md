# 强势股回测系统 - 项目分享包

## 📋 项目概述

这是一个完整的强势股量化投资回测系统，基于Python开发，用于测试不同持有期策略的投资表现。系统通过分析历史数据，模拟真实交易环境，评估1天、2天、1周持有策略的收益情况，并与沪深300基准进行对比分析。

## 🎯 核心功能

### 1. 多策略回测分析
- **持有1天策略**：每日调仓，持有1天后卖出
- **持有2天策略**：每2天调仓，持有2天后卖出  
- **持有1周策略**：每周调仓，持有5天后卖出

### 2. 智能股票筛选
- 基于动量指标的强势股筛选
- 自动跳过涨停股和数据缺失股票
- 等权重资金分配

### 3. 真实交易模拟
- 考虑交易成本（手续费0.0086%、滑点0.1%）
- 涨停股处理逻辑
- 资金重新分配机制

### 4. 详细分析报告
- 累计收益对比图表
- 胜率统计和夏普比率计算
- 最大回撤分析
- 详细交易记录CSV文件

## 📊 数据说明

### 输入数据文件

1. **daily_screening_results.csv** - 每日筛选结果
   - 包含字段：筛选日期、股票代码、股票名称、排名等
   - 每日筛选出前10只强势股
   - 格式：CSV，UTF-8编码

2. **trading_data.dta** - 股票交易数据
   - 包含字段：Stkcd（股票代码）、Trddt（交易日期）、Opnprc（开盘价）、Hiprc（最高价）、Loprc（最低价）、Clsprc（收盘价）
   - 用于计算买入卖出价格
   - 格式：Stata数据文件

3. **CS300.dta** - 沪深300基准数据
   - 包含字段：Trddt（交易日期）、Clsindex（收盘指数）
   - 作为基准对比
   - 格式：Stata数据文件

1. **策略对比图表**（PNG格式）
   - `1day_vs_benchmark.png` - 1天策略与基准对比
   - `2day_vs_benchmark.png` - 2天策略与基准对比
   - `1week_vs_benchmark.png` - 1周策略与基准对比
   - `all_strategies_vs_benchmark.png` - 所有策略综合对比

2. **详细交易记录**（CSV格式）
   - `1day_详细交易记录.csv` - 1天策略每笔交易详情
   - `2day_详细交易记录.csv` - 2天策略每笔交易详情

## ⚙️ 核心算法说明

### 1. 买入逻辑
- **买入条件**: 无持仓时买入
- **股票选择**: 使用前一日筛选的强势股（前10只）
- **价格计算**: 开盘价 × (1 + 滑点率0.1%)
- **涨停股处理**: 自动跳过涨停股（开盘价=最高价=最低价）
- **资金分配**: 等权重分配可用资金

### 2. 卖出逻辑
- **卖出时机**: 持有期满时卖出
- **价格计算**: 当日平均价 × (1 - 滑点率0.1%)
- **平均价定义**: (最高价 + 最低价) / 2
- **备用价格**: 数据缺失时使用买入价

### 3. 成本计算
- **手续费**: max(交易金额 × 0.0086%, 5元)
- **滑点**: 买入+0.1%，卖出-0.1%
- **总成本**: 交易金额 + 手续费

## 🐛 常见问题

### Q1: 程序运行时提示找不到数据文件？
**A**: 确保 `data/` 目录下包含所有必需的数据文件：
- `daily_screening_results.csv`
- `trading_data.dta`
- `CS300.dta`

### Q2: 依赖包安装失败？
**A**: 尝试以下解决方案：
```bash
# 升级pip
pip install --upgrade pip

# 使用国内镜像
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple/

# 逐个安装依赖
pip install pandas numpy matplotlib pyreadstat
```

### Q3: 回测结果异常？
**A**: 检查以下几点：
- 数据文件中的日期格式是否正确
- 价格数据是否有效（非空、非零）
- 股票代码格式是否一致

### Q4: 内存不足或运行缓慢？
**A**: 优化建议：
- 减少回测时间范围
- 增加系统内存
- 使用SSD硬盘提高I/O性能
