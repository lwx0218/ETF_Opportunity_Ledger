# 强势股回测系统 - 项目说明

## 📋 项目概述

这是一个基于Python的强势股回测系统，用于测试不同持有期策略的投资表现。系统通过分析历史数据，模拟真实交易环境，评估1天、2天、1周持有策略的收益情况。

## 🎯 核心功能

### 1. 多策略回测
- **1天持有策略**：每日调仓，持有1天后卖出
- **2天持有策略**：每2天调仓，持有2天后卖出  
- **1周持有策略**：每周调仓，持有5天后卖出

### 2. 智能股票筛选
- 基于动量指标的强势股筛选
- 自动跳过涨停股和数据缺失股票
- 等权重资金分配

### 3. 真实交易模拟
- 考虑交易成本（手续费、滑点）
- 涨停股处理逻辑
- 资金重新分配机制

### 4. 详细分析报告
- 累计收益对比
- 胜率统计
- 夏普比率计算
- 最大回撤分析
- 详细交易记录

## 📊 数据说明

### 输入数据
1. **daily_screening_results.csv**：每日强势股筛选结果
   - 包含股票代码、名称、筛选日期
   - 每日筛选出10只强势股

2. **trading_data.dta**：股票交易数据
   - 包含开盘价、收盘价、最高价、最低价
   - 用于计算买入卖出价格

3. **CS300.dta**：沪深300指数数据
   - 作为基准对比
   - 计算相对收益

### 输出数据
1. **策略对比图**：各策略vs基准的累计收益曲线
2. **详细交易记录**：每日买卖详情、持仓、现金
3. **性能指标**：胜率、夏普比率、最大回撤等

## ⚙️ 核心算法

### 1. 买入逻辑
```python
# 买入条件
if not current_positions:  # 无持仓时买入
    need_buy = True

# 涨停股判断
if 开盘价 == 最高价 == 最低价:
    continue  # 跳过涨停股

# 价格计算
实际买入价 = 开盘价 × (1 + 滑点率)
```

### 2. 卖出逻辑
```python
# 持有期满时卖出
if 当前日期 - 买入日期 == 持有天数:
    卖出价格 = (最高价 + 最低价) / 2 × (1 - 滑点率)
```

### 3. 成本计算
```python
手续费 = max(交易金额 × 0.000086, 5元)
总成本 = 交易金额 + 手续费
```

## 📈 性能指标

### 1. 收益指标
- **累计收益率**：策略总收益
- **年化收益率**：年化收益表现
- **超额收益**：相对基准的超额收益

### 2. 风险指标
- **最大回撤**：最大亏损幅度
- **夏普比率**：风险调整后收益
- **胜率**：盈利交易占比

### 3. 交易指标
- **总交易次数**：买卖交易总数
- **平均持仓天数**：实际持仓时间
- **换手率**：资金周转频率
