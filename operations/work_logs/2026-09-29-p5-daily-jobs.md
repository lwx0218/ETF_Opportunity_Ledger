## 复核发现与处理

| # | 发现 | 处理 |
|---|---|---|
| F1 高 | 实跑以 D 为 end，周末月末的恐慌信号当天认不出、次日又不回扫，永久丢失 | P2 月末判定改为「下一个工作日已进新月份」；新增从原始行情逐日现算的回放测试。节假日月末仍需交易日历，列入待决 |
| F2 高 | 北京 16:00 跑时海外容器没有当日行 | 改为北京 05:00–09:30 运行；默认日期 = A 股与海外都已收盘的最近日期 |
| F3 高 / 中 | 没有漏跑与数据新鲜度检查，停牌与数据迟到混为一谈 | 运行前检查：基准交易日、A 股序列当日必须有行、连续性（漏跑先补跑）；update 失败逐条报出；补跑不补立卡 |
| F4 中 | 机械卡把「固定源上无证据」写成冻结事实，其实没检索 | 理由改为「未检索」；schema 的表达列入待决，定之前恐慌规则不宜启用 |
| F5 中 | 没有现金约束；事件排序、出场口径是自补 | 进场加总风险 4% 与仓位合计 ≤ 100%；口径列入待决，配置须 `confirmed_terms` 才启用 |
| F6 中低 | 事件草稿：同日同容器第二条静默跳过、一条坏草稿挡住全部、论点被截断 | 逐条校验逐条报告；不截断；`scan_key` 带草稿序号；单张卡被拒不影响其余 |
| F7 低 | A3 论点作废路径没有 | 到期提醒；自动判定列入「不做的事」 |
| F8 低 | 作废原因判定顺序与 V1 不同 | 改为与 V1 引擎相同 |
| F9 低 | 截断测试抓不到实跑路径的问题 | 新增逐日现算的回放测试 |
| F10 低 | `cf_ew_level` 随容器集合变化 | 列入待决 |

没有产出任何研究结论：回放用的是构造数据，只验流程。
