## 501018（LOF）— 找到日频官方源

### 有效路径

- **页面**：`https://www.sse.com.cn/market/funddata/volumn/lofvolumn/`（HTTP 200，`channelCode=lofvolumn`）
- **API**：`https://query.sse.com.cn/commonQuery.do`
  - `sqlId=COMMON_SSE_SJ_JJSJ_JJGM_LOFGMTJ_L`
  - `SEARCH_DATE=YYYY-MM-DD`（或 `YYYYMMDD`）
  - `PRODUCT_TYPE=11,14,15`，`type=inParams`，`isPagination=false|true`
  - Header：`Referer: https://www.sse.com.cn/`
- **字段**（样例行）：
  - `TRADE_DATE`（如 `20261016`）
  - `FUND_CODE=501018`
  - `FUND_ABBR=南方原油`，`SEC_NAME_FULL=南方原油LOF`
  - `INTERNAL_VOL`：页面说明为**基金规模（万份）**，且为 **场内**规模（与集思录口径描述一致：上交所公布场内份额）

|---|---|
| 20260630 | 74,910.46 |
| 20260930 | 71,473.63 |
| 20261013 | 69,253.44 |
| 20261014 | 69,253.48 |

原件目录：`raw/501018/lof_daily/lof_YYYYMMDD.json`  
汇总 CSV：`samples/lof_501018_sample.csv`

`SEARCH_DATE` **会改变**返回的 `TRADE_DATE` / 份额（已用多日核对，不是“永远最新一日”）。

2026-10-10 请求返回空 result（约 522 B）——可能非交易日或该日未更新；已原样保留，未补点。

### 口径注意（写入 sources_map 时）

- `INTERNAL_VOL`：**场内**万份，**不是**基金全部份额。
- 东财 gmbd「期末总份额（亿份）」含场外，数值更大（例：2026-06-30 gmbd 期末总份额 8.20 亿份；同日场内 API 约 7.49 亿份=74910.46 万份）。折溢价/规模分析需标明用的是场内还是全份额。
- 基金公司站 `nffund.com` 产品旧路径 404；未登录、未下单。

### 建议修订 sources_map（501018）

- `shares_source`：SSE LOF 场内规模日频（`COMMON_SSE_SJ_JJSJ_JJGM_LOFGMTJ_L`）
- `shares_url_or_api`：上文 API
- `shares_freq`：daily（场内）
- `shares_unit`：万份（场内）；换算份 ×10000
- `status`：可由 `partial` 升为 `ok`（若产品接受「场内份额」口径）；并保留 gmbd 作全份额季频对照
- `notes`：强调场内 vs 总份额；QDII 净值滞后与折溢价对齐仍按原说明
