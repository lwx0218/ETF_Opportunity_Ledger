## 启动与复验

在仓库根目录使用 Python 3.12 及现有 requirements：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m src.web --mode market --port 8770
```

本轮本地真实观察入口为 `http://127.0.0.1:8770/?mode=market`，轮动页为 `/rotation?mode=market`。两页共用观察日期与容器，不能从此服务切换至演示或正式台账。下面是另开终端使用独立端口的纯演示命令：

```bash
.venv/bin/python -m src.web --mode demo --demo-only --port 8771 \
  --demo-dir outputs/observation-preview/demo
```

访问 `http://127.0.0.1:8771/?mode=demo` 与 `/rotation?mode=demo`。不加 `--demo-only` 的普通本机演示同样只显示合成观察、规则及数据状态，但允许用户显式进入 `?mode=readonly`；该切换才读取正式数据。服务默认仅绑定 `127.0.0.1`，没有生产认证与反向代理配置；普通演示及正式只读服务不得直接暴露至公网。已有 Pi 本机服务可经 SSH 转发：`ssh -L 8765:127.0.0.1:8765 <Pi主机>`。这些是启动说明，不代表已在 Pi 部署或复验。无 Node 构建或运行时依赖。

演示数据默认保存在忽略的 `outputs/app-demo/ledger.sqlite`。初次启动生成六张纯合成卡，初始时间为北京时间 2026-09-14 16:00；两页观察使用当前 37 容器声明和纯内存合成行情，六张卡对应价格沿用原演示公式。指标预热保留 600 个合成工作日；推进也使用合成工作日日历，不冒充交易所日历。重启保留状态，“重置演示”恢复初始样例并清除该演示内的操作。每个演示目录只启动一个服务实例；测试和并行预览使用独立 `--demo-dir outputs/my-demo`。不接受来自 HTTP 的数据库路径、时钟、成交价格或冻结字段。

演示数据格式升级时，旧库会被明确拒绝，不自动覆盖。保留旧演示可启动新目录，例如 `--demo-dir outputs/app-demo-v2`。不得用 `data/` 作为演示目录。

### 临时远程纯演示（Owner 已授权）

Owner 授权在已有 1Panel 防火墙控制下临时开放合成演示：任何能访问服务器的人均可查看和操作这份共享演示，无生产认证，不适用于正式数据或生产部署。本改动不自行修改防火墙，也不启动、停止现有服务；部署由主会话执行。

```bash
outputs/s1-venv/bin/python -B -m src.web \
  --host 0.0.0.0 --port 8765 --public-host 111.19.137.226 \
  --demo-only --demo-dir outputs/app-preview/demo
```

访问 `http://111.19.137.226:8765`。`--host` 仅接受 IPv4 字面量，默认仍为 `127.0.0.1`；非 loopback 监听必须指定明确的 `--public-host`，并启用 `--demo-only` 或下述 `--mode market`。公开 Host 不含端口、不接受通配符，仅额外放行该 IP 与实际监听端口的精确组合；`127.0.0.1:<端口>`、`localhost:<端口>` 仍可用。Origin 必须与当前 Host 完全同源，写入仍需 CSRF token 和 revision。

`--demo-only` 在应用层也禁止 `mode=readonly`（包括两页、state、观察 API、详情和直接方法调用），与 `--mode readonly` 组合会拒绝启动。所有 `demo` 请求的 state 和观察均只报告合成规则与数据，不调用正式行情预检、正式台账读取或正式规则配置；只有 `outputs/` 下隔离演示库可写。移除显式远程选项后，本机普通演示 / 正式只读行为保持不变。

### 真实行情公开只读预览（Owner 已授权）

Pi 已有 8765 公开入口采用 `market`，在已有 1Panel 防火墙控制下临时公开，无生产认证。准确提交部署与该实际入口复验由 Pi 执行；本地预览不替换 Pi 服务、不改变防火墙。沿用的启动参数为：

```bash
outputs/s1-venv/bin/python -B -m src.web \
  --host 0.0.0.0 --port 8765 --public-host 111.19.137.226 --mode market
```

`market` 仅读取 `data/market.sqlite`，使用 SQLite `mode=ro`、`query_only` 和只读快照；缺库不建、不迁移。两页展示按字段资格计算的观察：真实价格、RS、形态、ATR 和月末 z，不能据此称研究已就绪。进程内缓存随文件版本、请求参数和分钟时点变化失效。原 `(code, adj)` 行情登记清单保留为辅助检查，记录覆盖、来源及 NULL 数量，不再代替首页或轮动矩阵。

选定研究只认当前 coverage 的 `series_code/series_adj/route_used`。执行 ETF、未选价格候选各按自身身份显示，不替代研究序列。腾讯离线导入 `000852` / `000905` 保持 `price_only=true`、未纳入研究，与全收益序列分开；`H00300/raw` 是全收益指数，不能把 `raw` 一概称作价格指数。页面区分指数点位 / ETF 价格、价格 / 全收益及不复权 / 后复权，行情末日与服务读取时刻另列。

该模式不初始化演示或台账，不读取正式台账 / 卡片 / 持仓 / 扫描记录 / 规则配置，不投影作业参数、原响应、路径或密钥。首页明确“此观察入口不载入正式判断/扫描结果”，不能据此声称正式 0 卡、规则关闭、已扫描无机会；真实观察也不冒充机会卡。所有 HTTP POST 与直接应用写方法拒绝，`mode=demo` / `readonly` 查询及直接调用也拒绝，不提供写入 CSRF token。远程精确 Host 与同源校验沿用前述边界；普通 `demo` 及正式 `readonly` 仍不允许远程监听，`--demo-only --mode market` 组合拒绝启动。

默认本机模式和已验证 `--demo-only` 隔离不变。本机未来正式台账完全只读启动（不初始化演示库）：

```bash
.venv/bin/python -m src.web --mode readonly --port 8765
```

正式行情与台账分别是 `data/market.sqlite`、`data/ledger.sqlite`。读取使用 SQLite URI `mode=ro` 与 `query_only`，不调用会初始化台账的 `Ledger(...)`；缺台账显示空态，缺行情报告不可用，不建库、不迁移、不记录新来源。readonly 载入正式台账与实际规则配置；“配置启用”不等于“已扫描”，只有真实扫描记录才能证明执行。观察日、台账处理日 / 最新逐日记录与读取时刻分别保留。切换市场观察日期不会把之后的评分、出场结果解释为当时已知。

## 观察日期、字段与缺口

默认观察日按北京时间及 15:00 收盘边界，从官方 calendar 取已完成交易日。指定非交易日映射至不晚于请求日的最后官方交易日，返回请求日及有效日；日历未覆盖则明确无法确定，不猜工作日，不因行情滞后改成最后有数据的日期，不提供未来观察。每个周列是 W-FRI 周内截至观察日的最后官方交易日，未完成周标为截至当日；同列各容器共用该日。

每个读数保留容器、`code/adj/source`、用途、价格口径、观察日、原生日期、获取时间、计算窗口及具体不可用原因。历史是“按当前库版本重建截至 D 的行情”，不证明当时已获取、扫描或作出判断；`fetched_at` 不等于历史可得时点。海外 D 仅使用 `native_date < D`，先按原生日期算指标再对齐；连续第 5 个 A 股交易日无新行情即 `data_hole=1`，状态与排名不可用，旧真实值另带原日期。

| 字段 | 可展示条件及边界 |
|---|---|
| 原生价格图 | 正且有限的真实 close 可画线；完整且 high/low 包住 open/close 的 OHLC 才画蜡烛。缺日、缺字段及异常保留缺口和原因，不以 close 补 OHL、不扩价、不拼接别的序列。图窗只裁显示，不重置 EMA 或预热。 |
| 成交量 / 成交额 | 量柱要求与价格同序列、同日期及可追溯单位；当前单位未核定即不画，不填零、不借 ETF 量、不乘价格造金额。 |
| RS / 排名 | 选定研究 21 日收益减 H00300 同窗收益，必须有 22 个合格的对齐观察点；中间缺收盘不压缩，缺基准不退回绝对收益。当前 37 个 retained/flagged 容器全部保留；合法上市 / 预热边界单列，未知缺口令全池 rank 为 NULL，各自 RS 仍可显示。完整比较采用 `method=min`，并列同名次，展示按 universe 顺序；筛选不改分母。 |
| 形态 / ext | 复用既有 `form_states`，EMA10/20、SMA50、ATR14、20 日均量；观察须有 70 根合格原生行，覆盖 up_recent 所需历史，历史异常不能通过重置起点绕过。ext 除 ATR14，要求分母正且有限。 |
| 状态量源 | 每个观察日先截止再按 I-21 选量，缺量超过一半才借同一指数价格版本，并记录 self / price_version / none。历史周列不能受较晚数据的缺量比例影响；无量时明确形态受限，不能称完整状态判定，不借未核定的腾讯候选量。 |
| ATR20 | 原生 20 根 TR 简单均值；缺真实 OHLC、前收盘或包络异常即不可用。ATR20 用于风险 / 失效位，与形态内部 ATR14 分开；本包不更改正式研究既有异常修整政策。 |
| 月末 z | 完成月末 close 相对此前 20 个已完成月末的均值及样本标准差；其它日期显示最近值时保留真实月份，不能冒充当日值。样本不足、零标准差和月末缺收盘分别说明。 |
| NAV / 溢价 / 份额 | 缺合格来源、单位、市场日期或发布时间时明确欠项；不从价格变动推资金流，也不复制旧原型值。L1–L4、源头 / 目的地仍需各自证据，价格排名不能替代。 |

`benchmark_ready` 与 `research_ready` 是独立的全池只读质量状态；close 指标可用不放行缺 OHLC 的正式研究，不自动剔除容器。观察请求不调用正式 build、live、扫描或策略研究，不生成前向收益、买卖信号或效力结论，不改 Params、coverage、universe 或规则开关。合成演示不证明正式研究可用。

## 操作路径

首页以过去 / 当下 / 未来承接六问：今天有没有机会、当下在跑什么、下一个还差什么、上一次对不对、今天不碰什么、规则值多少。尚缺正式判断时仍可看合格观察与具体缺口；“无法判断”不等于投资禁入，“未扫描”不等于扫描无机会。

从首页的容器或“进入轮动”进入 `/rotation`，在 37 容器 × 周截面矩阵中选日期 / 容器，点格子追溯原生图、序列身份、指标窗口与不可用原因。研究、执行和独立价格候选分别选择；日期、容器、序列与模式随导航、刷新和深链接保留。深浅色、窄屏及键盘均需按同一旅程复验。卡片详情保留为何触发、何时退出、冻结论点 / 预期 / 失效条件、价格窗口、每日追加与证据；同类历史尚无可靠选样口径时明确不足，不挑盈利样本或用旧回放成绩预测新卡。

隔离演示完整流程：

1. 从“未来”打开国债或红利，查看冻结的论点、预期、失效条件和证据时点，填写 0–5 独立评分及理由；一次提交后封存，下一演示交易日开盘后过期。
2. 可将另一候选作废：原记录留在“已结 / 作废”，总分母不减少。
3. 从“当下”打开半导体，声明手动出场（须理由）或论点作废。提交只增加信号，仍处于持有状态。
4. 返回首页，推进一个演示交易日。现有 DailyJob 按下一有效开盘处理出场，卡片进入“过去”；继续推进记录出场后 20 日，再按冻结规则结案。
5. 深浅主题通过右上角切换；详情在同页展开，关闭后保留原页面与观察条件。正式只读入口没有写操作。

演示 OHLCV 与事件论点全部合成；指标使用已有 `src/indicators`，生命周期使用 `DailyJob`、`Ledger` 及原 `Params()`。观察请求本身不运行任务；“推进演示”才运行隔离样例的每日流程。演示事件只在内存中启用，绝不修改 `config/ledger-rules.json`。没有真实事件证据，样例明确登记“已检索无证据”，不伪造引用。月末 z 在预热不足时保持缺失。

## 双盲、冻结与评分审查

API 显式投影字段，不序列化带 `agent_strength` 的完整 `card_status`。Owner 入口始终不披露 agent 个体分数和理由，也不公开能反推其分桶的 agent 聚合；独立审查仍可使用已有台账校准方法。前端显示自己的校准桶，终态样本不足 30 时仅显示数量与“样本不足，不下结论”，不绘制效力曲线。作废计入分母；未评分、未检索和仍在途的数量分别保留。

审查只报告事实与触发状态，不改变规则。已接两条确定口径：最近 20 张已结卡的平均已实现 R ≤ −0.2，以及全部已出场中手动出场比例 > 30%。前者按结案记录时刻、卡号稳定排序，未满 20 张不判定。告警不代替人的“继续 / 停止 / 重开新版本”决定。

反事实区域展示创建时冻结的等权、沪深300、容器点位，以及库内已记录的所选基准已实现超额；它们不会被冒充为全部同期对照已完成。同期双基准重算需要明确可验证的窗口及端点，随机容器尚缺事前抽样池、种子与冻结时点；连续三季度反向的指标/样本门槛、年度审查起算日和结构变化的时点证据尚待编排方确认。页面列明这些未完成项，不补参数或事后随机抽样。

## 接口与测试

页面 `/`、`/rotation` 接受 `mode`、`as_of=YYYY-MM-DD`、`theme=Txx`、`series=research|execution|price_candidate`、`card=T-YYYY-NNN`。例如真实市场深链接：

```text
http://127.0.0.1:8770/rotation?mode=market&as_of=2026-09-30&theme=T01&series=research
```

GET `/api/state` 返回当前入口的台账 / 隔离状态；GET `/api/observation` 返回观察读模型，接受 `mode`、`as_of`、`theme`、`series` 及 `weeks=1..26`（默认 12）。GET `/api/cards/<id>` 保留冻结详情，仅 demo / readonly 可读。除观察接口外的 API 只接受 `mode` 查询；重复或未知参数拒绝，查询参数不能扩大服务启动时的模式权限。

POST `/api/cards/<id>/score`、`void`、`exit-signal` 及 `/api/demo/advance`、`reset` 仍仅用于演示。写请求须 JSON、当前 `revision` 与 `X-CSRF-Token`；陈旧页面返回 409，同源与 Host 检查保护本机入口。评分、作废与信号继续由数据库的追加/冻结/时限约束裁定；错误不回退为任意写入。

```bash
.venv/bin/python -m unittest discover -s tests -t .
node --check src/web/static/app.js
curl --fail 'http://127.0.0.1:8770/api/state?mode=market'
curl --fail 'http://127.0.0.1:8770/api/observation?mode=market&as_of=2026-09-30&theme=T01&series=research&weeks=12'
```

自动测试仅使用临时 / 内存库。既有流程检查覆盖冻结 / 双盲、过期和重复、HTTP 边界、只读缺库、文件保全、演示失败回滚与审查触发边界；本包另检查观察截止与未来数据不泄漏、缺 OHL 不补、缺日不压缩 RS、预热 / 并列 / 月末 / 海外断档、不完整池无完整排名及三种入口隔离。实际通过数、独立产品复核、Ponytail 与截图以本轮交付日志为准，不能由本说明推定已通过或已在 Pi 验收。

浏览器在同一实际启动模式下复验“首页 → 轮动 → 日期 / 容器 / 原生依据 → 返回 → 深链接刷新”，深浅色都检查两页及详情，再验证窄屏、键盘和演示完整生命周期。运行前后可用 `sha256sum data/market.sqlite` 核对正式行情保全；真实观察中实际查看的序列、日期和指标范围须登记到交付日志。

## 本包之后仍须完成

本包范围是两页观察与隔离演示，不代表完整 R5 / R6 或正式产品上线。欠项按[纠偏计划](../operations/planning/2026-10-06-product-recovery-plan.md)保留责任：

- 证据采集 → 草稿 → 确认 → 冻结、四层完整判断：编排确定来源 / 操作口径，Codex 接领域与页面，Pi 执行已定义采集。
- 正式盲评分、作废重建 / supersedes、出场信号入口：Codex 实现，编排复核，Pi 在合法启用后部署；公开 market 不承接正式写入。
- 完整 R6，包括独立审查、同期双基准 / 随机容器对照及未定触发器：编排先裁定，Codex 实现。
- NAV、份额、量额单位与增量数据：编排查证，Pi 取原件与全量验证，Codex 作必要适配。
- 正式研究、A7 后真实卡片及五个真实交易日无人值守：编排按预注册组织，Pi 在前置条件满足并获相应授权后执行；本包保持正式研究与规则关闭。

观察不是收益或策略效力结论。后续结论仍须声明 intake 的四项数据陷阱：主题指数回填偏差、指数与 ETF 差异及每年 1% 折扣、腾讯减法 qfq 不可直接算收益、价格与全收益口径不可混用。
