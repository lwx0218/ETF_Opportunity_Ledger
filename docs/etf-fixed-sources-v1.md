> card schema 规定：卡片 `evidence[]` 的每一条 `source_id` 必须来自固定源清单，而且要有硬发布日期。本清单就是那张清单。收录门槛、等级和「可用时点」规则由 Claude 依据下文理由决定，Owner 验收逻辑。2026-09-27 由四组并行核实完成，每个来源都实际打开过官方页面；打不开的如实标「待核」，没有凭记忆补。

## 1. 为什么要这样定

研究纪律第 2 条：证据只来自预先声明的固定源，且带硬发布日期。要防的是两种事后偏差：

- **挑选**：结果出来后，从几十条新闻里挑几条「对得上」的当证据；
- **时间错位**：把卡片创建时还没发布（或还没被看见）的信息算进去。

所以清单要回答三件事：哪些来源算数；每条信息**最早什么时候能被用**；证据如何留档，事后不能改。

## 2. 收录标准与等级

**收录**：政府与央行、交易所、国际组织、指数公司、上市公司法定披露等一手来源；行业协会或交易市场自行编制的统计标为「半一手」，可以收录，但在卡片上注明。

**不收录（只能当线索，不能当证据）**：新闻媒体与财经门户（新浪、财联社、路透、36 氪等）、数据聚合站（tradingeconomics、集思录等）、手机 App 推送、商业数据库（如 CCTD 的 CCI 指数）、二手汇编（如世界黄金协会的央行储备表，它转引 IMF 且滞后两个月）、需要付费订阅才能看到的数据（如 SEMI 北美设备出货月报）。媒体比官方更早拿到的消息（例如路透社先拿到 OPEC 月报副本）同样不算，以官方发布为准。

**等级**：

| 等级 | 含义 | 能否进卡片 |
|---|---|---|
| **A** | 一手或半一手；发布时刻可以核实到分钟（官方日程写明时刻，或页面 / 文件本身带时间戳） | 可以 |
| **B** | 一手或半一手；只能核实到日期，或时刻只有旁证 | 可以，但可用时点按保守规则（第 3 节） |
| **C** | 官方页面在核实环境里打不开，或节奏、时刻、存档至少一项没核实 | **不可以**，服务器端核实后才能升级 |

当前：A 级 19 个，B 级 24 个，C 级 17 个。

## 3. 可用时点规则（最重要的一节）

每条证据除了 schema 已有的 `published_at`，还要记两个字段：`first_seen_at`（我们的系统第一次抓到它的北京时间）和 `available_at`（这条证据最早可以被卡片使用的时点）。一条证据只能用于 `created_at ≥ available_at` 的卡片。

`available_at` 按下面顺序取：

1. **发布时刻到分钟（A 级）**：`available_at = 官方发布时刻`，换算为北京时间。
2. **只到日期（B 级）**：`available_at = max(发布日次日 00:00 北京时间, first_seen_at)`。也就是说，只知道日期的信息，当天收盘的卡片一律不能用，除非我们自己在当天收盘前已经抓到并留了快照。
3. **巨潮等「日期不可信」的来源**：公告标注的披露日与实际上网时间不一致（常在前一晚就能看到），`available_at = first_seen_at`，披露日只作参考。
4. **明确延迟的数据**：按延迟规则计。LME 免费库存按 T+2；两融按 T+1（核实后）；ETF 份额以接口返回的数据日期为准，不以抓取日为准。

举例（卡片在 A 股收盘后生成）：

| 信息 | 发布时刻（北京） | 能否进当天收盘的卡片 |
|---|---|---|
| 统计局工业增加值 | 10:00 | 能 |
| 台积电月营收 | 13:30 | 能 |
| 环渤海动力煤指数（周三） | 15:00 | 能（收盘时点发布） |
| EIA 原油周报（周三） | 22:30 / 23:30 | 不能，周四收盘的卡片才能用 |
| 美联储议息声明 | 次日 02:00 / 03:00 | 不能，次一交易日 |
| USDA WASDE | 次日 00:00 / 01:00 | 不能，次一交易日；北京时间跨日，最容易记错一天 |
| 证监会新闻（只到日期） | 当日，时刻不详 | 不能；除非当天收盘前已抓到 |

## 4. 留档与修订

- **快照**：每条证据在 `first_seen_at` 时保存原始 PDF / 网页 / 附件，并记录 sha256。原因：很多官方文件会被原地覆盖（EIA 的 psw00 文件、WSTS 的 xlsx、外汇局的年度页面附件、UKMTO 带 rev 参数的链接）。
- **修订**：官方数据被修订时，原证据不改；修订值作为一条新证据，带自己的时点。
- **证据一经写入卡片即锁死**（schema §2.5），本节只是说明写入时要带哪些字段。

给 R2（卡片存储）的实现要求：`evidence[]` 每条在 schema 字段 `{source_id, published_at, summary, url}` 之外，增加 `first_seen_at`、`available_at`、`snapshot_path`、`snapshot_sha256`；存储层校验 `source_id` 在本清单中且等级为 A 或 B，并拒绝 `available_at > created_at` 的证据。

## 5. 与 A3（事件驱动卡的论点失效）的关系

事件驱动卡的「论点失效条件」必须写成：「在 {日期} 前，{source_id} 发布 {可证伪的结果} 即失效」。指定的来源必须是 A 或 B 级；B 级来源按第 3 节规则判定时点。没有合格来源可指定的论点，只能用价格失效位。

| 容器 | A | B | C | 说明 |
|---|---|---|---|---|

| 农业 / 豆粕 | 4 | 3 | 1 | 覆盖最好：WASDE、农业农村部供需与周度价格、统计局季度生猪 |

| 地产 | 3 | 0 | 1 | 统计局房价与投资、LPR |
| 宽基 / 红利 / 国债 | 1–2 | 1–3 | 0–2 | 统计局、LPR、中证调样 |
| 煤炭 | 2 | 0 | 0 | 统计局原煤产量、环渤海动力煤指数 |
| 医药 / 创新药 | 1–2 | 0 | 1–2 | 医保局集采与目录；药监局待核 |
| AI/算力、通信/光模块 | 1–2 | 1 | 1 | **缺口**：没有比财报更早的官方统计。可用的都是间接信号（台积电、鸿海月营收，韩国出口，SEC 申报）；海关 HS 细分待核 |

| 光伏 | 1 | 1 | 3 | 硅料 / 硅片周价的原始发布渠道待核 |

| 新能源车、恒生科技 | 0 | 0 | 1–2 | 全部待核（中汽协、乘联会、港交所） |

**缺口的含义**：缺口容器的卡片证据会长期为空（schema 允许空数组，表示「当时固定源上没有证据」）。这本身就是要被校准的信息：如果一年后「无证据」的卡片和「有证据」的卡片表现一样，说明证据层不带信息（schema §6.1）。**不要为了填缺口去收录不合格的来源。**

## 8. 版本与冻结

- 第 7 节核实完成、台账上线之前，把本清单冻结为 v1，并在 Metadata 写明冻结日期。
- 冻结后只允许**追加**新来源（v1.1、v1.2……），每个新来源带「生效日期」；生效日之前创建的卡片不能引用它。已有来源的等级可以因核实而调整，但调整不影响已锁死的卡片。
- 删除来源（例如网站停更）只标「停用」和停用日期，不从表中删除，以便旧卡片仍能追溯。
