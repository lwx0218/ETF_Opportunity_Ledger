## 0. 一句话定义

在一个存量资金池里，**物理事件给钱一个去的理由，拥挤给钱一个走的理由**；两边同时成立、目的地的预期还没被打满、而源头出现价格确认的衰竭时，资金迁徙是高确定性的。

收益大小由目的地的预期差决定，方向由物理事件决定，触发由源头的衰竭决定，规模由池子有没有增量决定。

### 3.1 Kell 状态机 v0（规则，参数待用 2026 面板校准）

输入：收盘 C、EMA10、EMA20、SMA50、SMA200、ATR14、成交量 V、V20（20 日均量）。
`ext = (C − EMA10) / ATR14`；`up = EMA10 > EMA20 > SMA50`；`down = EMA10 < EMA20 < SMA50`。

| 状态 | 规则 |
|---|---|
| REV 反转延伸 | down 且 ext < −3 且 V > 1.5·V20 |
| POP 楔形突破 | 前 20 日多数收盘在 EMA20 下方；今日 C 上穿 EMA10 与 EMA20；V > 1.5·V20 |
| XB 均线回踩 | up 且 最低 ≤ EMA20×1.005 且 C ≥ EMA20 |
| BNB 平台突破 | up 且 前 15–30 日振幅 ≤ 3·ATR14 且 C 创 20 日新高 |
| EXH 衰竭延伸 | up 且 ext > +3 且 V > 1.5·V20 |
| DROP 楔形跌破 | 近 20 日曾 up；今日 C 跌破 EMA10 与 EMA20；V > 1.5·V20 |
| XBD 下行回踩 | down 且 最高 ≥ EMA20×0.995 且 C < EMA20 |
| BNBD 下行平台跌破 | down 且 前 15–30 日振幅 ≤ 3·ATR14 且 C 创 20 日新低 |
| TREND_UP / TREND_DOWN / NEUTRAL | 其余 |

## 6. 决策规则 v0（两种模式分开记）

**进攻**：L1 有效论点 且 目的地 KELL ∈ {POP, XB, BNB} 且 目的地 expectation ≠ extreme 且 PREM < 阈值（QDII/LOF：5%；A 股 ETF：1%）→ 进；目的地 KELL ∈ {DROP, EXH} 或论点被证伪 → 出。

**防守**：源头 KELL ∈ {DROP, XBD} 且 源头 FLOW_20 < 0 且 REGIME ≠ 增量 → 从源头撤到 {红利, 银行, 黄金, 现金} 中 RS_1M 最高的一个；源头 KELL 回到 {XB, BNB} → 撤销。

拥挤是条件不是触发：FLOW/VOL/PREM 只把容器标为「警惕」，动作必须等 KELL 的价格确认。

## 7. 回放与归因

回放单位是**周截面**：每周五收盘，对所有容器算状态向量 → 按规则出动作 → 持有到下一次动作。只跑容器集合，不跑全市场。

每笔交易三层 alpha（基准 = 当时的替代决策）：论点 alpha（vs 沪深300）、选择 alpha（vs 所有容器等权）、择时 alpha（vs 同一容器买入持有不动）。防守交易另记「少亏了多少」（vs 留在源头）。附 MAE/MFE 和按 KELL 状态分组的胜率。

论点回放必须 as-of：只能用 evidence 里日期 ≤ 决策日的证据；Teardown 事件流的时间戳就是依据。
