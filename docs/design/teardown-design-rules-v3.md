## 1. 一句话

**页面就是背景,部件就是产品;每一段先给结论,再给证据。** 没有容器,没有面板,没有卡片;层级只靠留白、字号和四档灰度建立。一屏一个主角,一屏不超过一段说明。

## 2. 结构模型

Explorer 是**同一种视图的递归**,不是一组页面:

```text
容器(机柜 / 交换机 / 光模块) → 模块(九个) → 部件 → …
```

每一级都是「一个容器 + 它的部件列表」。位置永远只由顶部面包屑表达(`CPO 光模块 › 硅光芯片 › 光调制器`),不做侧边树、不做标签页。
选中一层不是「弹出信息卡」,而是「这一层成为新的主角」:其余层退成 `--dim`,内容直接铺在页面上,一条 L 形引线把对象和标题连起来。`Esc` 或点击页面任意空白回到整机。

**分层图的来源要说清楚。** 现在的九个模块来自公开行业图示的命名,经 OIF co-packaging 术语核验(`docs/research-baseline/cpo-taxonomy.md`),是**研究分层,不是物理拆解**:光接收多集成在 PIC 内,光源可外置,主板属系统边界。界面上写「九个模块」不写「九层结构」,页脚注明一次。做到交换机 / 机柜一级时再换成物理保真的视图。

## 3. 字体

| 用途 | 字体 | 说明 |
|---|---|---|
| 正文、标题、中文 | `Geist`(拉丁与数字)→ 系统中文字体(苹方 / 微软雅黑) | 自托管 `web/public/fonts`,OFL;不下载 CJK 字体 |
| 编号、代码、ticker、eyebrow、读数 | `Geist Mono` | 只做小字标注与数字,永远不是主字体;数字开 `tabular-nums` |

字号刻度(px):11 读数小标 · 12 eyebrow · 13 small · 14 表格 · 15 body · 17 lead/row · 34 h2 · 56 h1 · 68 display。
eyebrow 一律大写、字距 0.14em、`--muted` 色。

## 4. 颜色

浅色与深色各一套变量,同名;组件只引用变量,不写死色值。**每个新页面必须同时出浅深两版**,深色不是反色,是单独调过的一套。

| 变量 | 作用 |
|---|---|
| `--bg` | 页面背景。浅色是暖白,深色是近黑 |
| `--ink` / `--ink-2` / `--muted` / `--faint` | 四档文字灰度:标题 / 正文 / 标注 / 装饰 |
| `--hair` / `--hair-2` | 发丝线。列表分隔与引线只用它们 |
| `--accent` | 唯一强调色。只用于:链接、当前引线、选中态的 eyebrow、悬停高亮、事件类别标签 |
| `--sig-pos` / `--sig-neg` / `--sig-neu` | **方向色**,见 §5 |
| `--m-*` | 分层图材质(铝、PCB、裸片、硅光、金、基板、黑塑)。深色版单独调过 |

不用渐变背景,不用彩色徽章,不用阴影卡片。分层图的投影是唯一允许的阴影。

## 5. 方向色(语义轴)

界面上除强调色外只有一条有语义的颜色轴:**对资金方向是正向(pos)/ 负向(neg)/ 中性或状态量(neu)**。默认 A 股习惯红涨绿跌;设置里可切成绿涨红跌,切换只改变量,不改组件。

方向色只允许落在三种地方:

1. **方向标记**:`▲ 偏多` / `▼ 偏空` / `● 中性`,mono 12px。字形承担方向,色盲也能读。
2. **带正负号的数字**:`+3.1%`、`−0.6%`、`+2.1σ`。无符号的状态读数(分位、占比)按阈值着色,阈值写在读数旁边一行(如:高于 80 分位或 +1.5σ 视为脆弱 → 偏空;低于 20 分位视为出清 → 偏多;其余中性)。
3. **结论行**的方向标记(见 §6)。

正文、标题、表格文字一律墨色。层上的活动点(呼吸动画,`prefers-reduced-motion` 时静止)用方向色表示该层篮子的方向。

## 6. 结论先行

每个分析段(资金投票、拥挤度、卡口事件、共振、事件效力、判断)的**第一行是结论**:方向标记 + 一句话,15–16px 墨色;正文、读数、表格都在它后面。读者扫一遍页面,有色的地方就是要判断的地方。

结论的方向是由规则算出来的,不是文案写的:判断的方向由作者选;拥挤度、事件反应、篮子偏离的方向由阈值决定。

## 7. 时间语义

**没有「裸」读数。** 每段头部都带 `截至 <日期 收盘> · 窗口 <…>`;必要时再带计算口径(`反应 = T+1 相对篮子`)。四类量分开处理:

| 量 | 窗口 | 时效 | 说明 |
|---|---|---|---|
| 事件反应 | T+1 / T+3 / T+5 相对同环节其他公司的等权篮子(公司,不含自己)或整机篮子(层级事件) | 默认 T+5,由该环节「事件效力」的半衰期校准;半衰期只用观察够天数的事件 | 每条事件一列「时效」:`窗口内 T+2/5` / `已定价` / `过期` / `未反应` |
| 事件效力 | 滚动 90 天,每周重算 | 统计量,写明样本数与分类 | 给出 T+1/T+5/T+20 平均超额、命中率、半衰期 → 事件信号有效期 |
| 拥挤度 / 脆弱性 | 20 日,每日重算 | **状态量,不是信号**,不会过期只会变化 | 分位、σ 偏离、成交占比;按 §5 的阈值着色 |
| 判断 | 作者设定(如 2 个季度) | 到期自动进收件箱回顾;每次卡口事件后重新记分 | 必须有验证指标与失效条件,带阈值的会被自动跟踪 |

一段结论的时效取它所有输入里最短的那个。

## 8. 组件词汇(只有这几种)

- **eyebrow + 标题 + 一段说明**:每个区块的头;右侧放 `截至 · 窗口` 与动作链接。
- **结论行**:方向标记 + 一句话。
- **hairline rows**:所有列表与表格。网格列、上边一条 `--hair`、悬停时标题变 `--accent`。窄栏(≤ 560px)里的事件表用两行式(公司 · 类别 / 事件标题),不塞超过四列。
- **读数行**:`标签 + mono 数字` 横排、可换行,数字按 §5 着色。
- **leader line**:锚点小圆 + 1px 线,连接图与文字。
- **面包屑**:唯一的位置指示。
- **mono 小标注**:编号、ticker、证据级、时效。

需要新组件时,先问「能不能用上面几种拼出来」。

## 9. 文案

- 中文为主;英文只作 mono 小标注或专名。不做「英文 / 中文(括号解释)」三段式标签。
- 界面上不出现只有开发者才懂的词:轮次号、实现术语、边界声明、免责段落。笔记文件路径可以出现,因为它对用 Obsidian 的作者有意义。
- 证据级用三个词:**已核验 / 候选 · 待核验 / 行业图示**。来源信息放在公司页,整页只在页脚出现一次来源说明。
- 样例数据一律在页脚标「样式示例」;接入真实数据后删掉这句。
- 没有数据就不放这个模块,不放 `Unknown` 徽章。空态是一句话。
- 从资深投研的视角写:事件重要是因为它驱动资金投票;写清楚「谁在买、买的是哪一段、还能管多久」,不写百科式介绍。

## 10. 禁区

- 卡片套卡片、每个 section 一个白底圆角框
- 顶部堆叠多层标题 / 说明 / 筛选器才见到内容
- 同一信息在一页内重复出现(如来源路径出现两次)
- 为了「完整」而加的 tab、filter、dashboard、badge
- 把 prototype 或图示里的数字(份额、BOM%、国产化率)当成事实展示
- 只有颜色没有字形或符号的方向表达;正文里用颜色
- 没有 `截至 / 窗口` 的读数;把状态量(拥挤度)写成信号

## 11. 布局与响应

当前为桌面优先:内容宽 1280,页边 80,Explorer 的图与标注使用固定坐标(见 `ExplorerPage.tsx` 的 `OVERVIEW` / `FOCUSED`)。选中态右栏宽 540,公司页右栏 360,研究页右栏 300。
小于 1280 的视口尚未适配;移动端不在 v1 范围。
